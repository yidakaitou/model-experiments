# 模型实验与诊断

> 我能把模糊的问题变成可测量、可复现的实验，并且**诊断它为什么失败**。

这里的三个项目不是"作品展示"，是三次**排查**。每个项目里最值钱的部分不是最终指标，是"我以为问题在 A，结果在 B"。

## 一、我做过什么

### [01 · 状态参与计算](./01-state-modulation/)
**问题**：让模型的内部状态（情绪、疲惫度）真的参与判断，而不是当附加文本拼进去。
**做法**：四组对照（纯文本 / 纯状态 / 拼接 / FiLM 每层乘性调制），3 个随机种子。
**结果**：FiLM **0.786 ± 0.0046**，拼接 0.495（等于随机猜）。**+29 点。**
**代价发现**：门控学习率必须 ≥1e-2，否则增益归零——这个坑如果不测，会误判"机制无效"。

### [02 · 结构化抽取能力](./02-memory-extraction/)
**问题**：让 8B 模型从对话里可靠地抽取事实，而不是编造。
**做法**：自己构造训练数据 → LoRA 微调 → **5 个泛化留出集** → 黑箱对抗测试。
**结果**：同分布 1.00；泛化 0.89–1.00；自检 0.98（归属版 156 题 1.00）。
**关键发现**：**四个"模型能力问题"，全部是数据 bug。**（见 [踩坑记录](./docs/踩坑记录.md)）

### [03 · 带信念的 agent](./03-agent-with-memory/)
**问题**：外部记忆如何替代权重记忆，并且能处理"人会变"。
**做法**：`valid_to` + `supersedes` 的信念库，冲突时失效而不是覆盖；质量闸拦截坏数据。
**结果**：40 窗口长程测试，最终记忆状态全部正确，旧值可追溯。

## 二、我真正擅长的是诊断

这三个项目里，我的判断都不是一次到位。实际的路径是这样：

| 我一开始以为 | 实际是 | 怎么发现的 |
|---|---|---|
| 模型太小，抽不准 | 数据标签行被 shuffle，**根本不可学** | 逐条对比预测 vs 标准答案，发现 23/24 是"同槽不同值" |
| 加数据没用 → 数据不够 | 训练和测试**表述形式不一致**（第三人称 vs 第一人称） | 直接 diff 训练集和测试集的同类句子 |
| 泛化突然变差 = 过拟合 | 输入长度**超出训练分布** | 按长度分桶看准确率 |
| 上线后乱编 | 训练集 100% 都有答案，**没教它"闭嘴"** | 在无事实的真实对话上测，发现 86% 强行抽取 |

**这四次的共同点：我先怀疑模型，后来都证明是我的数据或评测有问题。**

## 四、方法论（可复用的部分）

### 判据一：加数据/加 epoch 无效 → 先查数据格式

这条是从四次失败里归纳出来的，不是看来的。**模型训不好时，第一反应应该是"我的标签对不对"，而不是"换个更大的模型"。**

### 判据二：同分布满分 ≠ 能用

必须准备**独立于训练分布的留出集**。我在项目二里准备了五个，每个考不同维度：

| 留出集 | 考什么 |
|---|---|
| paraphrase | 换一种说法还认不认 |
| noise | 口语填充词干扰 |
| novel | 训练集没见过的值 |
| multispeaker | 混入别人的话，会不会串台 |
| long | 长对话里事实被淹没 |

**只报一个总分会掩盖这些问题。** 比如我的模型在前四项 0.95+，但 multispeaker 只有 0.19——**它把别人说的话记成了用户的**。总分掩盖了这个。

### 判据三：先分清"能力问题"和"信息问题"

项目二最后做过一组 A/B/C 对照：

| 组 | 输入格式 | 规则兜底 | 结果 |
|---|---|---|---|
| A | 整段对话 | 有 | ✅ 通过 |
| B | 整段对话 | 无 | ❌ 失败 |
| **C** | **显式标注 `[提问]`/`[回答]`** | **无** | ✅ **通过** |

**同一个模型，只改输入格式，失败变成功。**

结论：不是模型不会，是**"这句话在回答哪个问题"这个信息根本没传进去**。

**这让我明白拼装式系统的真正瓶颈在接口，不在模型。**
